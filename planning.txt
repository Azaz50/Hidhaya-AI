# Hadith Number Rule (IMPORTANT)

For Hadith references:

The official Hadith number is:

NOT:

* internal id
* database id
* array index

Example:

This rule must be applied consistently across:

* AI responses
* search APIs
* bookmarks
* citations
* frontend rendering
