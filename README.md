# Hidhaya AI

> Your Personal Islamic Companion AI

Hidhaya AI is an AI-powered Islamic guidance platform designed to provide authentic, simple, and emotionally supportive Islamic answers using Quran and Hadith references from local datasets.

The platform focuses on:
- Authenticity
- Trust
- Semantic Islamic Search
- Multi-language Support
- AI-powered Simplified Guidance

# 🧠 Advanced Islamic AI Engine

Hidhaya AI uses a Retrieval-Augmented Generation (RAG) architecture.

AI DOES NOT generate Islamic references itself.

Instead:
1. Quran & Hadith references are retrieved from local datasets
2. AI simplifies and explains the references
3. Responses remain authentic and trustworthy

---

# 🔍 Advanced Semantic Search

Includes:
- Exact matching
- Semantic matching
- Fuzzy search
- Intent detection
- Topic mapping
- Cross-language understanding
- Query normalization

Example:
- "धैर्य" → sabr
- "gussa" → anger
- "shirk" → polytheism
- "bachon ki talim" → tarbiyah

# 🛡️ AI Safety Rules

Hidhaya AI:
- NEVER invents Quran verses
- NEVER invents Hadith
- NEVER generates fake references
- ONLY uses references from local datasets

If no exact reference exists:
> “Please consult a qualified Islamic scholar.”
